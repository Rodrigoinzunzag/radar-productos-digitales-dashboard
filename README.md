# Radar de Productos Digitales

Dashboard estático del Radar de productos digitales validado desde Facebook Ads Library.

- Fuente de datos: Google Sheets.
- Actualización automática: cada 48 horas.
- Publicación: GitHub Pages.

El archivo `index.html` es generado automáticamente por `/opt/data/productos-digitales/radar_vivo_productos_digitales.py`.
